## Обо мне

Привет! Я Кирилл — учусь, чтобы творить, и строю всё, что придумываю: от маленьких утилит для Windows до целых платформ.

- Сейчас развиваю **Harek** — микроядро рабочего пространства, SDK с типизированными контрактами и экосистему плагинов
- Верю в подход *Learning by building*: каждый проект — повод освоить что-то новое (Rust, микроядерная архитектура, TUI)
- Интересуюсь вебом, UI, экспериментами и инженерией

### Остальное

- **[harek-sdk](https://github.com/kirillsql1kaa11/harek-sdk)** — SDK со строгими типизированными контрактами для платформы Harek (TypeScript)
- **[Harek-Plugin-Forge](https://github.com/kirillsql1kaa11/Harek-Plugin-Forge)** — мастерская плагинов: генерация стартеров, валидация манифестов, упаковка (TypeScript)
- **[ITD-Extended-Client](https://github.com/kirillsql1kaa11/ITD-Extended-Client)** — UserScript-клиент для ИТД: модульная система и UI-улучшения (JavaScript)
- **[YM-Track-Downloader](https://github.com/kirillsql1kaa11/YM-Track-Downloader)** — расширение для скачивания треков с Яндекс Музыки в MP3 320 kbps (Manifest V3)
- **[keyflow-24h](https://github.com/kirillsql1kaa11/keyflow-24h)** — трекер клавиатурной активности со скользящим 24-часовым окном для Windows (Python)
- **[autonomous-coder](https://github.com/kirillsql1kaa11/autonomous-coder)** — самообучающаяся нейросеть для генерации и автодополнения кода (Node.js)
- **[itd-random](https://github.com/kirillsql1kaa11/itd-random)** — веб-эксперимент: [itd-random.vercel.app](https://itd-random.vercel.app) (TypeScript)
